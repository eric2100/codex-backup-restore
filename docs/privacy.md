# 隱私與資料處理

本儲存庫公開的是技能、驗證程式、文件與合成測試。程式無遙測或網路上傳功能；所有路徑與資料均由操作者在本機指定。

## 本機產物不是公開素材

工具產生的清單含來源絕對路徑、相對檔名、大小及雜湊；比較報告也可能揭露個人目錄、專案名稱或檔案結構。SQLite 檢查會把資料庫與 sidecar 暫時複製到系統臨時目錄，因此應確認臨時磁碟的存取權限與可用空間。一般刪除不等於鑑識等級安全抹除。

以下項目應留在本機受保護的位置，不能提交到公開 Git：

- Codex 聊天、記憶、附件、歷史及完整資料庫／WAL／SHM。
- `auth.json`、含 token 的設定、cookie、SSH 私鑰與其他認證。
- 真實備份、來源 manifest、還原報告、日誌、主機資訊或使用者目錄。
- 包含上述資料的 ZIP、快照、測試 fixture 或 Git 舊提交。

`.gitignore` 只能減少誤加檔案，不能保證防洩漏，也無法撤回已發布的提交。發布前應逐檔審查 staging 內容及提交作者資訊。

## 回報問題

提供程式版本、Python 版本、匿名錯誤碼、返回碼，以及能用合成資料重現的最小步驟。用 `<USER>`、`<BACKUP>`、`<PROJECT>` 等佔位文字代替真實識別資訊。

不要直接貼完整 stdout、traceback 或報告。先移除實名、帳號、電子郵件、絕對路徑、備份識別碼、遠端主機、專案／檔名與憑證。若誤公開憑證，先撤銷／輪替憑證，再處理檔案和 Git 歷史；單純刪除最新檔案不足以補救。
